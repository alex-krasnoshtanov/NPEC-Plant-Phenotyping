# NPEC plate images (not included)

This folder holds the raw fisheye-corrected NPEC root plate photos the simulation renders
as specimens. They are third-party research data and are NOT redistributed here; they are
also large (~8-9 MB each). The `.gitignore` excludes their contents but keeps this note.

To run anything that needs a rendered plate, place the NPEC plate PNGs in this folder.
